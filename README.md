О проекте:
Наш проект направлен на сокращение пищевых отходов. Наше приложение помогает пользователям найти точку питания с нераспроданной едой. Кафе, рестораны и пекарни могут продавать остатки еды по заниженным ценам, тем самым уменьшать количество отходов и сопутствовать экологическим целям страны.

Проблема:
Продукты питания выбрасываются из-за приближения или истечения срока годности, хотя часть продуктов остается пригодной для употребления.
Цель:
уменьшить количество отходов, сократить финансовые потери точек питания, предоставить потребителю приобрести товар по низким ценам
Решение:
Приложение с картой, где пользователь видит заведения которые выставляют свои продукты питания с акциями от 30% до 80%. Некоторые заведения могут выставить оставшиеся блюда на выбор или собрать коробку с сюрпризом.
